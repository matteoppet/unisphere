# Overview
**UniSphere** is an open-source, student-focused web application built to organize university courses, deadlines, and study sessions.
Instead of the passsive to-do lists, UniSphere combines clean solo academic tracking with **optional** group tracking and sessions.

---

## Key Feature
### Core Workspace (Solo Mode)
You can track your university life without being the interruption of squads or friends.

### Squad Hub
All the features of squads live exclusively inside the "Squad" page, you can either create or join a group, and track all your progress between others. You can also study together in a live session library or a more competitive option: Beat your mate to a straight study session.

---

## Local Deelopment Setup
You can run UniSphere locally or build a new feature by following these steps:

### 1. Clone the repository
```bash
git clone [https://github.com/matteoppet/unisphere.git](https://github.com/matteoppet/unisphere.git)
cd unisphere
```

### 2. Install Dependencies
You can use npm or bun:
```Bash
npm Install
# or
bun install
```
### 3. Copy Environment Variables
Copy the .env.example file to .env in the root directory and replace with your own API keys

### 4. Start the development server 
```Bash
npm run dev
```
